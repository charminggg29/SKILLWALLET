# API Data Rendering (Plain React via CDN)

This project demonstrates: 
- Fetching JSON data from a public API (JSONPlaceholder)
- Loading state
- Error handling
- Rendering a dynamic list with unique keys
- Reusable components (Loader, DataList)

## How to run
1. Open `index.html` in a browser.
2. Ensure internet access (CDN + API call).

## Notes
- Because Node.js/npm is not installed on this machine, this is implemented as a plain HTML file using React UMD builds + Babel for in-browser JSX.
- In a production setup you would use Vite/CRA.
